R-2026-10-25-A. Housekeeping in the test field

Entered 25 October 2026. Rule entry R-2026-10-24-A is extended to the test field, for one purpose only: removing internal approval notes, such as a note that a change was approved or when it was approved. Nothing else in a test may be removed under this rule. Removal never changes a row's outcome, date, owner, test meaning, sources or result. Where an approval note cannot be taken out without changing what the test says, it stays as published.

How it is shown. As under R-2026-10-24-A, each removal is listed in data/housekeeping-log.csv with the date, the update, the row id, the field, and the row's fingerprint before and after, one line per fingerprint layout. The build accepts a changed test only when the log lists it and the change deletes one stretch of text; a test can never be replaced with OPEN, and any other change still stops the build. Earlier dated files stay as published, so anyone can compare a row before and after.

First use, update 2026-10-25a: row HOUSING-STARTS (test). In the same update, row BEC1 (date source) has an approval note removed under R-2026-10-24-A. The rows before the change are in public-live-rows-2026-10-24c.csv (and, for the v1 layout, public-live-rows-2026-10-18.csv).

This rule applies from 25 October 2026 forward. R-2026-10-24-A stays as entered.
