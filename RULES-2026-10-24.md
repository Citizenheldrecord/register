R-2026-10-24-A. Housekeeping

Entered 24 October 2026. Housekeeping (24 October 2026): internal working notes (approval notes, timestamps, internal file references) are not part of the record and may be removed from any row. Removal never changes a row's outcome, date, owner, test, sources or result, and is shown in the published file fingerprints.

How it is shown. Each removal is listed in data/housekeeping-log.csv with the date, the update, the row id, the field, and the row's fingerprint before and after. The changed row gets a new fingerprint in the next dated manifest, and that manifest names the log and its checksum. The build accepts a changed fingerprint only when the log lists it, and only when the change is in the date source, measure, money, funding or essay field and either deletes text or replaces it with OPEN; any other change still stops the build. Earlier dated files stay as published, so anyone can compare a row before and after. This is the one exception to the rule that an entry is never edited after it goes in.

First use, update 2026-10-24a: rows BM1, KAMLOOPS-EXCAV, EA-REFORM (date source), QC-SEATMATH (essay) and COVID-RESIDUE (measure).

This rule applies from 24 October 2026 forward.
